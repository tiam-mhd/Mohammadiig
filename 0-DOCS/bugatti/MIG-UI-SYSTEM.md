## 1. فلسفه و اصول غیرقابل‌مذاکره

### ۱.۱ ایدهٔ مرکزی
صفحه مثل یک **فیلم نمایشگاهی** رفتار می‌کند، نه داشبورد:
- بوم تقریباً سیاه
- عکاسی / تصویر محصول = ولتاژ بصری
- تایپوگرافی نرم و شکیل = راهنما
- UI کم‌حرف، بدون کروم تزئینی

### ۱.۲ قدرت نرم (Soft Power)
قدرت برند با **شتاب‌زدگی تایپ یا رنگ جیغ** نشان داده نمی‌شود؛ با:
- فضای خالی کنترل‌شده
- مقیاس تایپ متعادل (نه یوغور و غول‌پیکر)
- دکمهٔ outline شفاف (pill)
- حرکت آرام

### ۱.۳ سه اصل محتوایی
1. **فارسی سلیس** برای صنف شهربازی (نه شعار ادبی)
2. **انگلیسی** فقط برای برند لاتین (`MIG`)، ایمیل، لیبل‌های فنی ضروری — با فونت Bugatti
3. **یک کار در هر سکشن**: یک عنوان + یک توضیح کوتاه + حداکثر یک CTA اصلی

### ۱.۴ تست برند
اگر هدر/لوگو را برداری و صفحه بتواند مال هر برند دیگری باشد، برندینگ ضعیف است. لوگو و عکاسی محصول باید هویت بسازند.

## 4. تایپوگرافی

### ۴.۱ خانوادهٔ فونت (نهایی پیاده‌سازی‌شده)

| نقش | فارسی | انگلیسی (Bugatti) |
|-----|--------|-------------------|
| Display / تیتر | **Noto Naskh Arabic** | **Saira Condensed** |
| Body / UI خوانا | **Vazirmatn** (۳۰۰/۴۰۰) | **Cormorant Garamond** |
| Mono / لیبل لاتین | — | **JetBrains Mono** |

### ۴.۲ قوانین فونت
- تیتر فارسی → همیشه `font-display-fa` (Naskh) — نرم و شکیل
- بدنه و دکمهٔ فارسی → `font-ui` (Vazirmatn)
- هر متن انگلیسی → کلاس `.en` / `.en-mono` / `.en-text` یا `lang="en"`
- وزن پیش‌فرض: **۴۰۰** (Bold برای سلسله‌مراتب ممنوع؛ اندازه کافی است)
- برای فارسی: `letter-spacing` زیاد و `uppercase` اجباری ممنوع

### ۴.۳ مقیاس تایپ (متعادل — نه غول‌پیکر)

| کلاس | تقریباً | کاربرد |
|------|---------|--------|
| `.display-monumental` | clamp ~1.45–2.75rem | فقط هیرو اصلی |
| `.display-feature` | clamp ~1.25–2rem | تیتر سکشن / بند عکسی |
| `.display-section` | ~1.2–1.625rem | آیتم منوی تمام‌صفحه |
| `.body-lead` | ~0.94–1.05rem | توضیح کوتاه |
| `.caption-up` | ~11px | کپشن / eyebrow |
| `.nav-link` | ~12px | منو / فروشگاه |
| `.btn-pill` | ~13px | برچسب دکمه |

**یادآوری اصلاح:** مقیاس‌های Bugatti ۲۸۸px برای جایگزین‌های open-source قابل استفاده نیستند — سقف منطقی حفظ شود.

## 5. فاصله، گرید و ریتم صفحه

### ۵.۱ Shell محتوا
کلاس: `.content-shell`

| Breakpoint | `padding-inline` |
|------------|------------------|
| موبایل | `max(1.5rem, safe-area)` |
| ≥480 | `2rem` |
| ≥768 | `3rem` |
| ≥1024 | `4rem` |
| ≥1280 | `5rem` |
| max-width | `1720px` |

**قانون:** متن، دکمه و باکس‌ها هرگز به لبهٔ ویوپورت نچسبند.

### ۵.۲ فاصلهٔ عمودی سکشن
- بین فصل‌های مارکتینگ: `SectionGap` ≈ `3–7rem` (موبایل کمتر، دسکتاپ بیشتر)
- داخل بند عکسی: کلاس `.section-copy`
  - بالا: ~4.5–6rem
  - پایین: موبایل ~6.5rem + safe-area · دسکتاپ ~18–22vh
- محتوا نباید به لبهٔ پایین سکشن بچسبد

### ۵.۳ تراز متن (`text-align`)
| نوع سکشن | تراز |
|----------|------|
| معرفی / خدمات / محصولات / جزئیات | `start` (راست در RTL) |
| دعوت به اقدام کوتاه / جملهٔ هویتی | `center` |
| هیرو دسکتاپ | ستون راست (دور از سوژهٔ عکس اگر ماشین چپ است) |
| هیرو موبایل | `start` ولی بلوک در **بالای** فریم (نه روی سوژه) |

## 6. شکل‌ها، دکمه، ورودی

### ۶.۱ Radius
| عنصر | Radius |
|------|--------|
| عکس، جدول، اکثر کانتینرها | `0` |
| دکمهٔ اصلی | `pill` (`9999px`) |
| باکس شناور / منو کارت نرم | `12–16px` (استثنا برای لطافت شناور) |
| پنل utility کوچک | حداکثر `6px` |

هیچ `rounded-xl` تصادفی روی کارت‌های مارکتینگ.

### ۶.۲ دکمهٔ اصلی — `.btn-pill`
- پس‌زمینه شفاف
- بوردر سفید ۱px
- `min-height: 44px` (لمس)
- Hover: پر شدن سفید + متن سیاه · transition ~450ms نرم
- فارسی، بدون uppercase اجباری

### ۶.۳ ورودی (فرم‌ها / پنل)
- پس‌زمینه شفاف یا `surface-soft`
- ترجیحاً underline یا بوردر `hairline`
- فوکوس: بوردر سفید ۱px — بدون glow رنگی
- خطا: بدون قرمز جیغ؛ پیام `muted` + بوردر سفید/هشدار کنترل‌شده

## 7. ناوبری، لوگو، منو

### ۷.۱ هدر
- ارتفاع: موبایل ~56px · دسکتاپ ~64px · `position: fixed` شفاف
- چیدمان سه‌تایی:
  - **منو** در `start` با فاصله از لبه (`start-10` … `start-28` + safe-area)
  - **لوگو** مرکز: `/Logo-DarkMode.png` با `.brand-logo` و `mix-blend-mode: screen`
  - **فروشگاه** در `end` با فاصله متقارن
- متن «گروه صنعتی محمدی» در هدر **جایگزین لوگو شده** — تکرار نکن

### ۷.۲ منوی تمام‌صفحه
- کلاس‌ها: `.menu-overlay` + `.menu-overlay__aurora` + `.menu-overlay__veil`
- بک‌گراند: **گرادیان دارک متحرک واضح** (نه سیاه تخت، نه محو نامرئی)
- لینک‌ها وسط‌چین، فاصلهٔ لمسی کافی، ورود تدریجی
- `Escape` و قفل اسکرول body هنگام باز بودن

### ۷.۳ لوگو
- فایل: `frontend/public/Logo-DarkMode.png`
- ارتفاع حدود `2.15–2.5rem`
- Alt: «گروه صنعتی محمدی»

### ۸.۱ ریتم Bugatti (Cinema Stack)
```

…
```

- بدون نوار آمار پرزرق‌وبرق روی هیرو

### ۸.۲ Hero
| دستگاه | رفتار |
|--------|--------|
| موبایل | متن **بالای** فریم؛ `object-position` ماشین را پایین می‌آورد؛ scrim قوی از بالا |
| دسکتاپ | متن در ستون امن (دور از سوژه)؛ scrim جانبی |

محتوای نمونهٔ هیرو:
- Eyebrow کوتاه
- عنوان: «طراحی، تولید، مشاوره»
- یک جملهٔ ساده
- CTA: «مشاهده محصولات» + لینک فرعی «درخواست قیمت»

**ممنوع:** متن روی صورت/بدنهٔ ماشین.

### ۸.۳ PhotoBand
- props: `eyebrow`, `title`, `body`, `cta`, `align`, `overlay`
- موبایل: overlayهای چپ/راست → تبدیل به گرادیان از پایین (خوانایی)
- ارتفاع موبایل ~68svh · دسکتاپ ~78svh

### ۸.۴ ModelBand
- نام محصول + توضیح ساده + دکمه «جزئیات محصول»
- تراز `start`

### ۸.۵ کامپوننت‌های مشترک
- `PhotoBand`, `ModelBand`, `Reveal`, `FloatingConsultCard`
- `Button` / `.btn-pill`
- `Header`, `Footer`

## 9. فوتر

ساختار سه‌لایه (از قبل پیاده‌شده):

1. **Intro:** معرفی یک‌خطی + CTA «درخواست مشاوره»
2. **Body:** ستون برند (لوگو/MIG) + کاوش + همکاری + تماس — فاصلهٔ ستونی سخاوتمند
3. **Bottom:** کپی‌رایت + حریم خصوصی / شرایط

قوانین:
- لینک‌ها شلوغ و چسبیده نباشند (`gap` ~0.95rem بین آیتم‌ها)
- ایمیل با فونت `.en-mono`
- بدون ایموجی، بدون آیکن رنگی تزئینی

## 10. کارت شناور مشاوره

- کامپوننت: `FloatingConsultCard`
- `position: fixed` روی کل ویوپورت (نه absolute داخل هیرو)
- گوشهٔ `inset-inline-start` پایین
- `border-radius: 16px` · blur · سایه نرم
- قابل بستن
- موبایل: بدون انیمیشن bob؛ رعایت `safe-area`
- z-index زیر هدر منو (`~45`)، بالای محتوا

متن پیشنهادی:
> برای پروژه جدیدتان نیاز به مشاوره دارید؟  
> همین حالا پیام بدهید

## 11. حرکت و انیمیشن

| حرکت | کاربرد | حس |
|------|--------|-----|
| `mig-fade-up` | ورود تیتر/CTA | نرم، ~1.55s |
| `Reveal` | اسکرول سکشن | translateY کم (~12px) |
| `kenburns` | هیرو | scale حداکثر ~1.035 در ۴۰s |
| `slow-pan` | بند عکسی | بسیار ملایم |
| `menu-aurora-*` | پس‌زمینه منو | قابل‌مشاهده، نه محو |
| `float-card-bob` | فقط دسکتاپ | اختیاری؛ موبایل خاموش |

`prefers-reduced-motion: reduce` → همه انیمیشن‌ها خاموش.

**ممنوع:** bounce، glow نئون، پارالاکس شلوغ، hoverهای پریده‌رنگ.

## 12. ریسپانسیو و موبایل

### ۱۲.۱ Breakpointهای عملی
| نام | عرض | تمرکز |
|-----|------|--------|
| Mobile | <768 | لمس، safe-area، هیرو بالای فریم، بند کوتاه‌تر |
| Tablet | 768–1023 | انتقال به چیدمان دسکتاپ |
| Desktop | ≥1024 | ستون‌ها، فاصله بیشتر |
| Wide | ≥1280 | padding-inline 5rem |

### ۱۲.۲ قوانین موبایل (اجباری)
1. هدف لمس ≥ ۴۴px
2. CTAهای هیرو می‌توانند تمام‌عرض ستونی شوند
3. لوگو truncate/سایز کنترل‌شده تا با منو برخورد نکند
4. متن روی سوژهٔ عکس = باگ
5. فاصله از لبه کمتر از ~1.5rem نباشد
6. منو/فروشگاه از لبه فاصلهٔ واضح داشته باشند

### ۱۲.۳ تحلیل آموخته از صفحهٔ اول
| مشکل | علت | راه‌حل مرجع |
|------|-----|-------------|
| متن ناخوانا روی ماشین | justify وسط + عکس مرکز | متن بالا + object-position پایین + scrim قوی |
| چسبیدن به لبه | padding کم | `.content-shell` پلکانی |
| چسبیدن به پایین سکشن | `justify-end` بدون pb کافی | `.section-copy` با pb بزرگ |
| منوی سیاه تخت | بدون aurora | گرادیان متحرک قوی |
| فوتر شلوغ | ستون‌های فشرده | فوتر سه‌لایه با gap |

## 13. محتوا و لحن فارسی

### ۱۳.۱ مخاطب
صاحب شهربازی، پیمانکار مجموعهٔ تفریحی، خریدار دستگاه — نه مخاطب مجلهٔ لوکس انتزاعی.

### ۱۳.۲ بله / خیر
| بله | خیر |
|-----|-----|
| دستگاه، سالن، نصب، قیمت، پشتیبانی | تجربه را مهندسی می‌کنیم، امضای تازه، خانه تجربه (مگر در جای تعریف‌شده) |
| درخواست قیمت / مشاوره | Discover / Enquire (انگلیسی UI) |
| جملات کوتاه و روشن | قلمه سلمبه و شعار ادبی |

### ۱۳.۳ زبان رابط
- تمام لیبل‌های UI فارسی
- استثنا: `MIG`، ایمیل، کدهای فنی
- اعداد قابل‌نمایش با `fa-IR` در قیمت‌ها

## 14. پنل ادمین / مشتری

همان پالت و فونت، با تفاوت‌های زیر:

| موضوع | مارکتینگ | پنل |
|-------|----------|-----|
| تراکم | کم، سینمایی | متوسط–زیاد |
| سکشن gap | 3–7rem | 1–1.5rem |
| Hero عکسی | بله | خیر |
| جدول | نیست | `hairline` بین ردیف‌ها، بدون سایه |
| سایدبار | نیست | `surface-soft` |
| دکمه | pill outline | pill outline + secondary خاکستری |
| Status | نادر | `warning` / `success` فقط |

### ۱۴.۱ AdminShell
- پس‌زمینه canvas
- ناوبری کناری یا بالا با `.nav-link` / Vazirmatn
- عنوان صفحه با `.display-feature` یا کوچکتر
- بدون تم بنفش/کرم قدیمی

### ۱۴.۲ DataTable
- هدر `muted`
- ردیف‌ها جدا با hairline
- اکشن‌ها متنی یا pill کوچک
- موبایل: کارت‌ستونی یا اسکرول افقی کنترل‌شده — نه فشردن ۶ ستون در عرض ۳۷۵
